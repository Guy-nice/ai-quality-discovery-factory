# Glossary

**Version:** v0 | **Date:** 2026-10-22

Terms marked `TO CONFIRM` need an organizational definition. Local meanings may differ.

## Evidence classes

| Term | Definition |
|---|---|
| FACT | Directly supported by a trusted source. |
| EVIDENCE | Specific artifact, metric, incident, ticket, report, or code observation. |
| HYPOTHESIS | Plausible but unproven explanation. |
| ASSUMPTION | Working assumption that must be validated. |
| UNKNOWN | Important missing information. |
| CONTRADICTION | Conflicting evidence or incompatible claims. |
| RECOMMENDATION | Proposed action based on evidence and stated trade-offs. |
